## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Tech Stack

- React
- Vite
- CSS Modules / standard CSS files
- React Router style page navigation
- Lucide icons

## Notes

This project is a photography portfolio website with sections for home, service pages, profile showcases, testimonials, FAQ, and contact.
