# Stories by Nadodikalaignan - Website Admin & Maintenance Guide

## 1. Overview
The website has a built-in, **zero-backend, zero-database** Admin Panel with:
- 🔐 Secure 3-step login (Username + Password + Email OTP)
- ☁️ Direct **Cloudflare R2** file upload from the browser (no FTP needed)
- 🎨 Clean, simple white UI — easy for non-technical users
- 🚀 1-click live publishing to `www.nadodikalaignan.com`

---

## 2. Accessing the Admin Panel
- **URL**: `https://www.nadodikalaignan.com/admin` (or `http://localhost:5173/admin` during development)

### Login (3 Steps):
1. **Enter Username + Password** → Click "Send OTP to Email"
2. A **6-digit OTP** is emailed to `sbnadodikalaignan@gmail.com`
3. **Enter the OTP** → Click "Verify & Login"

> **Default credentials:**
> - Username: `admin`
> - Password: `nadodi@2024`
> - OTP is valid for **5 minutes**

---

## 3. Uploading Images & Videos to Cloudflare R2

Each gallery section has an **"Upload to R2"** button. Use it to upload files directly from your computer:

1. Click the **blue "Upload to R2"** button in any section
2. Select an image (`.webp`, `.jpg`, `.png`) or video file from your computer
3. A **progress bar** shows upload progress
4. After upload, the URL is automatically filled in and saved
5. Click the **Add** button to save to the gallery

Uploaded files go to `https://media.nadodikalaignan.com/...` automatically.

**Alternatively**, you can still paste any existing R2 URL directly into the URL field.

## 5. How Changes Go Live

### 1-Click Live Publishing
1. Click **"Publish Live"** in the top right corner
2. Changes commit to GitHub automatically
3. `www.nadodikalaignan.com` updates in **~45 seconds**

#### One-Time Token Setup:
- Click the ⚙️ **Settings icon** in the top bar
- Paste your GitHub Personal Access Token (PAT with `contents:write`)
- Click **Save** — stored in your browser session

## 6. EmailJS Setup (OTP Email — One-Time Setup)

To activate OTP emails, configure EmailJS:

1. Go to [https://www.emailjs.com](https://www.emailjs.com) and create a free account
2. Create a **Service** (e.g., Gmail) → note the **Service ID**
3. Create an **Email Template** with variables: `{{otp}}`, `{{to_email}}`, `{{studio}}`
   - Set "To Email" field to: `sbnadodikalaignan@gmail.com`
4. Note your **Template ID** and **Public Key**
5. Update `.env` in the project:
   ```
   VITE_EMAILJS_SERVICE_ID=service_xxxxxxx
   VITE_EMAILJS_TEMPLATE_ID=template_xxxxxxx
   VITE_EMAILJS_PUBLIC_KEY=xxxxxxxxxxxx
   ```

> **Note**: Until EmailJS is configured, in development mode the OTP is printed to the browser console (DevTools → Console tab).

|---------|-----------|

| Latest Work | `images/latest/` |
| About Cards | `images/about/` |

| Portraits | `images/portraits/` |
| Toddlers | `images/toddlers/` |
| Pre-Wedding | `images/pre-wedding/` |
| Albums | `images/albums/` |

All files are publicly accessible at `https://media.nadodikalaignan.com/<folder>/<filename>`.

> **Important**: Make sure CORS is enabled on your R2 bucket to allow browser uploads:
> In Cloudflare Dashboard → R2 → Bucket → Settings → CORS:
> ```json
> [{"AllowedOrigins":["*"],"AllowedMethods":["GET","PUT"],"AllowedHeaders":["*"],"MaxAgeSeconds":86400}]
> ```
